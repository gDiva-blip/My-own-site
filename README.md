# My Own Site

This is a clean personal portfolio website template built for showcasing your story, skills, work, and contact information.

## What’s included

- A modern landing page with hero section, about section, skill cards, projects, and contact CTA
- Responsive layout for mobile and desktop
- Simple JavaScript for animations and mobile nav behavior
- Pure HTML/CSS/JS setup so it runs without any install step

## Run locally

Open `index.html` in your browser, or serve the folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Update the placeholders in `index.html`:

- Your name
- Intro text and headline
- Skills and project details
- Email and social links

You can also customize colors and styling in `styles.css`.
